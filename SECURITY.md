# Security scope and reporting

This is a loopback-only synthetic demonstration. Do not use it with real customer data or expose the demo HTTP server publicly. See [the threat model](docs/security-model.md) for controls and residual limitations.

For a vulnerability, use GitHub's private vulnerability reporting when enabled on the published repository. If it is not enabled, contact the repository owner privately before sharing sensitive details. Never attach live credentials or customer records to an issue.

No security certification or production-hardening claim is made. Dependencies are limited to Python's standard library; the optional model runtime and Docker base image have their own update requirements.
